# CBR addon
  
😎[wiki](https://github.com/XColorful/CBR-addon/wiki#English) | 📄[docs](https://github.com/XColorful/CBR-addon/tree/HEAD/docs)

This mod is an add-on created by the author of [Custom BattleRoyale](https://github.com/XColorful/BattleRoyale). Therefore, its source code also serves as a demonstration of how to use the Custom BattleRoyale API.

`This mod needs to be installed on the server.`

## Extended Features

(This project is in an early stage, so there are few extended features.)

### Zone special function

- Entity loot zone: You can use distribution algorithms to specify the position where entities spawn and write NBT data into the entity.
> Example: You can create TNT that rapidly falls from a fixed height in a golden spiral (uniform distribution) pattern.
